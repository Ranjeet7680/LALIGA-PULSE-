1. Optical Telemetry Ingestion (Sportian Mediacoach TRACAB)

The optical tracking array consists of 8 to 16 synchronized high-frame-rate cameras installed in the stadium catenary, capturing real-time spatial positioning of all 22 players and the ball at 25 frames per second.

Field Name Type Frequency Description

2. Adaptive Latency Synchronization Buffer

Global broadcast feeds suffer from physical delivery variance:

  • In-Stadium Spectators: 0.0s delay
  • DTT / Terrestrial Antenna: +3.5s delay
  • IPTV / Cable: +8.2s delay
  • OTT Streaming (LALIGA+): +18.4s delay

To eliminate spoilers, the client SDK uses an Adaptive Latency Sync Engine that listens to an inaudible acoustic watermark or extracts HLS ID3 timed metadata tags from the user's video feed. Prompts appear synchronized to that specific fan's screen.

4. Data Protection & Security Boundary (GDPR & UAE PDPL)

LALIGA PULSE adheres to Privacy-by-Design principles. Fan identity is decoupled from behavioral telemetry using an ephemeral cryptographic token tied to LALIGA Single Sign-On (SSO). Geofencing is calculated on-device without continuous server tracking.
